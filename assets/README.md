# Assets

Visual material for the project. Filenames expected by the README:

| File | Content |
|---|---|
| `screenshot-flujo.png` | Screenshot of the workflow canvas in n8n |
| `screenshot-chat.png` | Screenshot of the bot conversation (language menu + summary + audio) |

Guidelines:

- PNG format, 1200–1600 px wide.
- Crop the browser chrome and any personal data (chat IDs, names).
- Before uploading a screenshot, make sure no API key or private instance URL is visible.
- Large video files (`*.mp4`) are gitignored on purpose: attach them to a GitHub Release instead
  of committing them, so clones stay small.
